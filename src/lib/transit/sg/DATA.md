# Singapore transit data — sources and licences

`sgTransit.data.json` is generated by `scripts/build-sg-transit.ts`. Do not edit it by hand.

| Data | From | Licence |
|---|---|---|
| Bus stops, bus routes (stop order + distance), first/last bus | LTA DataMall `BusStops` / `BusRoutes`, via `cheeaun/sgbusdata` `data/v1/raw/*.datamall.json` (refreshed 2026-10-01) | Singapore Open Data Licence v1.0 |
| Bus service type (trunk vs city-direct / premium / shuttle) | `cheeaun/sgbusdata` `data/v1/raw/bus-services.json` (scraped from lta.gov.sg) | used only to drop non-trunk services |
| MRT stations (codes, names, locations) and station exits | `cheeaun/sgraildata` `data/v1/sg-rail.geojson` (v5.1.0, 2026-07-12), built from LTA TrainStation / Train Station Exit data | LTA data under the Singapore Open Data Licence v1.0; the repo also merges OSM and Citymapper-derived points for newer stations |
| Sentosa Express stations | hand-placed in `network.ts` (approximate) | — |
| Interchange walking times, run-time formula, waits | estimates in `network.ts` | — |

Attribution required by the Singapore Open Data Licence (show it wherever these
journeys are displayed): **"Contains information from LTA DataMall accessed on
1 October 2026 from https://datamall.lta.gov.sg, made available under the terms
of the Singapore Open Data Licence version 1.0."**

To replace the estimates with official data, get a (free) LTA DataMall account
key: the GTFS rail timetable feed (Aug 2026) gives real station-to-station run
times and headways, and `BusServices` gives bus frequencies.
